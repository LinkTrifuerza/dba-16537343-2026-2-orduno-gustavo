
# Actividad 12 — Privacidad por diseño

## ¿Qué problemas identificas?

El principal problema es que el sistema solicita más datos personales de los que realmente necesita para funcionar desde el momento del registro. 

## ¿Qué principio de privacidad se está ignorando?

Se ignora el principio de minimización de datos, este principio exige recolectar únicamente la información indispensable para prestar el servicio, dejando fuera todo lo que sea opcional o innecesario.

## ¿Qué preguntas realizarías antes de aprobar el diseño?

* ¿Para qué función específica del sistema es indispensable solicitar cada uno de estos datos?
* ¿El usuario tiene control para decidir qué campos llenar y cuáles dejar en blanco?
* ¿Qué medidas de protección se van a aplicar a los datos almacenados?

## ¿Qué datos eliminarías?

Eliminaría campos no esenciales como ocupación, ingresos o ubicación exacta.

## ¿Qué datos requerirían una justificación adicional?

Datos como el teléfono, la ubicación o la edad requerirían una justificación clara para conservarlos, el área correspondiente debe demostrar que hay una justifiacion real para conservarlos y comprobar para que.

## ¿Cómo aplicarías privacidad por defecto?

Configurando la plataforma para que desde el inicio solo pida el mínimo de información necesaria para la cuenta, ademas de que en caso de que llegara a necesitar un dato extra para algo en especifico hacerselo saber al usuario y que sea decicion de el si lo da o no.
