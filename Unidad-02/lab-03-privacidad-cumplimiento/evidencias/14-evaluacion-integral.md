
# Actividad 14 — Escenario Integral

| Problema                                                                        | Principio afectado                           | Riesgo                                                                                                          | Control propuesto                                                                                              |
| :------------------------------------------------------------------------------ | :------------------------------------------- | :-------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------- |
| **1. Acceso directo a datos sensibles por Analítica**                    | Limitación de acceso y necesidad de conocer | Consulta no autorizada de datos identificables de 50,000 clientes por personal que solo requiere estadísticas  | Implementar vistas anonimizadas o agregadas para el área de analítica sin acceso directo a la tabla original |
| **2. Analítica utiliza datos identificables sin requerirlos**            | Minimización de datos                       | Exposición innecesaria de nombres, correos y teléfonos cuando solo se generan reportes mensuales              | Ocultar o eliminar columnas identificables en las herramientas que usa el equipo de analítica                 |
| **3. Retención de información durante 12 años**                        | Limitación del plazo de conservación       | Acumulación masiva de datos antiguos vulnerables a filtraciones y posibles sanciones de autoridades            | Definir una política de retención que elimine o anonimice datos tras terminar la relación con el cliente    |
| **4. Ausencia de política documentada de retención**                    | Responsabilidad proactiva y legalidad        | Desconocimiento del tiempo de vida de la información y falta de sustento ante una auditoría                   | Redactar y formalizar un documento oficial con los plazos de conservación para cada categoría de dato        |
| **5. Uso de bases de datos reales en entornos de desarrollo**             | Privacidad desde el diseño y seguridad      | Filtración masiva de datos reales si el servidor de desarrollo o las laptops de programadores sufren un ataque | Generar bases de datos sintéticas (ficticias) o aplicar enmascaramiento antes de entregar copias a desarrollo |
| **6. Copias completas entregadas a desarrolladores**                      | Minimización y proporcionalidad             | Multiplicación de réplicas de la base de datos sin control ni registro de quién las conserva                 | Restringir las entregas a extractos mínimos de datos de prueba no reales y auditar su descarga                |
| **7. Uso de correos para marketing sin registro de finalidad**            | Limitación de la finalidad                  | Envío de publicidad a clientes sin su consentimiento explícito o sin opción de cancelar la suscripción      | Solicitar autorización previa para fines promocionales y permitir al cliente darse de baja de campañas       |
| **8. Falta de documentación sobre la finalidad de cada dato**            | Transparencia y lealtad                      | Incumplimiento de normativas de privacidad por recopilar información sin un propósito justificado             | Crear un inventario o matriz de datos donde se especifique la función operativa de cada campo                 |
| **9. Concentración de datos personales en una sola tabla**               | Privacidad por defecto y aislamiento         | Un solo acceso compromete toda la información sensible del cliente de forma simultánea                        | Segmentar la base de datos en zonas (operativa, fiscal y analítica) con permisos independientes               |
| **10. Falta de control y registro sobre quién consulta la información** | Integridad y confidencialidad                | Imposibilidad de detectar quién extrajo o filtró información en caso de un incidente interno                 | Usar logs para registrar cada acceso y consulta realizada a la base de datos                                   |
